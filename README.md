# ENV3040C_Final_Project

### Data Description
File: JZ_Data_Description.ipynb

It contains the means, medians, and standard deviations of each relevant variables. In addition, it includes four histograms, each of which contain ambient and elevated conditions.


### Correlation
File: JZ_Correlation.ipynb

It includes the following elements: the Pearson and Spearman Correlation Coefficients, Linear Regressions, and scatter plots of each relevant variables.


### Dimensionality Reduction and Clustering
File: JZ_Dimensionality_Reduction_Clustering.ipynb

It contains the following items: the Principle Components Analysis, principle component weights and its bar chart, k-means clustering and its bar chart, and PC1 and PC2 scatter plot. 


### Original Dataset
File: Li_et_al_2023_Gas_Exchange_Sheet.csv

It contains a dataset created from researchers Li and his team.
